# PM 项目复盘教练系统

面向 PM 求职者的 WorkBuddy Skill，用于辅助项目 review 和沉淀复盘笔记。

## 解决的问题

AI 已经能直接生成比用户自己写得更深入的项目笔记，但问题在于用户没有真正消化这些内容。本系统不替代用户理解，而是作为复盘教练引导用户在人机互动中完成对项目的深度吸收，把 AI 辅助产出的内容变成自己的认知。

## 核心功能

十阶段流程：项目类型识别 → 复盘框架建立 → 资料证据提取 → 基础复盘带练（互动提问、纠偏、追问因果关系）→ 理解抽测 → 深度复盘（产品判断、方案取舍、面试风险标注）→ 完整沉淀稿 → 表格布局 → Excel 笔记输出 → 质量检查。

每一步有准入门槛，抽测不通过就停，产出明显比原始资料薄则回退补齐。单次流程产出面试讲解稿和结构化知识白板两份资产。

## 技术亮点

- **Orchestrator-Worker 多 Agent 架构**：1 个总控调度 8 个执行 Agent，流程在 prompt 中定义，模型运行时自主判断进度与质量
- **三级证据分类体系**：每条信息标注资料依据、合理推断或待确认，从机制层面约束 AI 幻觉
- **防变薄质量机制**：阶段闸门 + 基础抽测 + 厚度检查，产出明显比原始资料薄则回退补证据

## 安装

将本仓库 clone 到 WorkBuddy 的 skills 目录：

```bash
git clone https://github.com/yu828yyy/pm-review-coach-skill.git ~/.workbuddy/skills/pm-review-coach
```

安装后无需额外配置，在 WorkBuddy 中通过关键词即可触发。

## 使用方式

在 WorkBuddy 对话中输入以下任一关键词触发：

- `复盘`
- `项目复盘`
- `PM复盘`
- `帮我复盘`
- `项目笔记`

首次使用时系统会询问用户称呼，后续自动复用。

### 输入

- 项目名称
- 项目资料路径（PRD、原型、数据报表等）
- 逐字稿路径（可选，与老师/导师讨论项目的对话记录）
- 已有笔记路径（可选）

### 输出

| 产物 | 用途 |
|------|------|
| 完整复盘沉淀稿 | 面试复习母稿，含 3 分钟讲解稿 |
| 结构化 Excel 知识白板 | 随时翻阅复习 |
| 基础复盘对话摘要 | 用户在哪里卡过、怎么讲通的 |
| 深度复盘框架与结论 | 面试风险标注、简历包装边界 |

## 使用场景

产品实习生、产品新人、PM 求职者在项目结束后，与 AI 教练互动完成深度复盘，将项目经历转化为面试可用的知识资产，不做 AI 的搬运工。
